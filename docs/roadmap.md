# Roadmap

**V1 — Explore with living matter.** A polished movement companion in a small open world.

**V2 — Plan a heist together.** The matter becomes an accomplice. Enemies use conventional game logic. Gameplay design will be developed separately.

**V3 — Intelligence on both sides.** Explore Jev-controlled enemies interacting with the companion, using bounded perception and fair physical rules.

V2 and V3 are ideas for future work, with no release dates.
